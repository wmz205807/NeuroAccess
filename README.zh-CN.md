# NeuroAccess

[English](README.md) | **简体中文**

**面向脑科学与 EEG 教育的开源 AI 平台**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

NeuroAccess 是一个免费的开源教育项目，用 AI 与交互式可视化，让脑电图（EEG）和神经科学更容易理解。

## 为什么做 NeuroAccess？

EEG 与神经科学对初学者和学生的门槛很高。现有的 EEG 工具大多面向研究人员，需要专业知识才能上手。

NeuroAccess 的目标是降低这道门槛：把 AI 辅助解释、交互式 EEG 可视化与教学资源放在一起。

## NeuroAccess 能做什么

- AI 辅助的 EEG 分析与解释
- 交互式 EEG 波形可视化
- 脑电信号的教学式探索
- 面向初学者的学习路径
- 支持神经科学与 EEG 教育
- 面向开发者与教育者的开源工具与资源

## 我们的做法

NeuroAccess 被设计为一个教育工具，而不是医疗或临床系统。

它不提供医疗诊断，也不做临床决策。

项目可以配合示例 EEG 数据集直接体验，因此无需提供个人脑电数据，也能学习和实验。

## 开源

NeuroAccess 在 GitHub 上公开开发（[wmz205807/NeuroAccess](https://github.com/wmz205807/NeuroAccess)）。

目标不只是做一个网站，而是建立一个可访问的开源项目——学生、教育者、研究者和开发者都可以探索、改进并在此基础上继续构建。

欢迎贡献代码、提出建议、报告问题，或分享教学场景中的使用方式。

## 愿景

我们相信，前沿的神经科学教育不应只局限在实验室或专家圈子里。

NeuroAccess 希望借助 AI 与开放技术，让脑科学更容易被理解和接触。
